For AI coding agents

Run several agents without losing track.

Claude Code, Codex and Gemini each in their own window and worktree — with a clear signal for which one needs you.

One-click agent CLIs

Claude Code, Codex, Gemini, Copilot, Cursor Agent, OpenCode, Qwen Code, Aider — or your own command — in a fresh shell from the palette. When the agent exits you drop back to the local shell, and after a reboot Claude, Codex, Gemini and Copilot tabs come back resumed.

A git worktree per agent

Each agent task is cut into its own worktree and opens as its own project tab — three agents working at once, zero overwriting. An orange dot warns when two of them touch the same file.

Know who needs you

A working agent pulses green on its tab and dock chip, a quiet one pulses amber; one blocked on an “Allow this tool?” prompt goes red — on the tab and its project, with the exact command and Approve / Deny buttons when hooks are on (nothing is answered without your click unless you opt in to a scoped rule — never for risky commands). Run termdeck hooks install to add the optional Claude Code, Codex, Copilot or Gemini CLI hooks and the state is exact, with the current tool and file; without them it falls back to output heuristics. termdeck never answers a prompt unless you click Approve / Deny, or opt in to a scoped rule.

One queue for the fleet

A single popover lists every agent tab across all projects, ranked needs approval → waiting → working. Click a row to jump to it — token totals per agent and project, as the agent reports them (Claude Code, Codex).

Review, then land it

Read-only diff of a worktree against the commit it was cut from — select a hunk and send it, with its file and line range, to an agent tab (typed, never run) — then merge it or open a PR and clean up the worktree, without leaving termdeck. Nothing is deleted without your confirm.

Private by default

Runs on your machine. No cloud, no telemetry, no API keys — your agents’ output never leaves localhost. Optional session logs for an audit trail.

Optional: exact agent state — wires up Claude Code, Codex, Copilot and Gemini CLI hooks. It shows what it will change and asks first; add --dry-run to only preview.
npx @kiril6/termdeck hooks install

Features

Everything, one screen.

Six things you'd normally wire together by hand — built in.

Floating windows

Drag, resize, tile into a grid, tabs per pane. Group windows into project tabs and switch context instantly.

Session reattach

Refresh the browser or drop your connection — the shell keeps running. A 60s grace timer holds the PTY and replays the buffer.

Durable with tmux

With tmux installed, shells survive a server restart or crash — not just a browser refresh.

Real filesystem tree

A live sidebar rooted at the active project. Open a shell in any folder; reveal files in Finder/Explorer.

Command palette

⌘K for fuzzy actions, sessions, and reusable snippets. Category chips (Terminals, Agents, Layout, Workspace…) narrow the list — Tab cycles them. Broadcast input to every shell in a project.

Themes & polish

Dracula, Nord, Gruvbox, Tokyo Night, Catppuccin and more. GPU rendering, font zoom, clickable links and file paths, pixel pets.

Quick start

Requires Node.js 18+. No build step, no Electron.

1
Fetch and run in one command — no clone needed (or npx github:kiril6/termdeck straight from GitHub)
npx @kiril6/termdeck
2
Keep it installed — puts termdeck on your PATH for daily use; npx above runs once and leaves nothing behind
npm i -g @kiril6/termdeck
3
Or clone it — setup picks the right node-pty prebuilt for your OS, then serves on localhost:3000
node install.js && npm start
4
Optional: install tmux first — shells then survive a server restart, not just a browser refresh
brew install tmux
5
Optional: exact agent state — hooks for Claude Code, Codex, Copilot and Gemini CLI; shows what it changes and asks first (--dry-run to preview)
npx @kiril6/termdeck hooks install
This is a local-first tool, not a static site. Its core is a Node process that spawns real PTYs — so it runs on your machine, not on GitHub Pages. This page is just the showcase; grab the code and run it locally.
